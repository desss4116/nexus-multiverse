# BLACKSITE: OPERATOR — Unity Android Prototype

A Unity 2022.3 LTS project for an atmospheric investigation game. The current prototype creates a dark 3D operations room at runtime and includes three clickable evidence items and a case-resolution sequence.

## Android build
The GitHub Actions workflow uses GameCI Unity Builder and requires a Unity Personal license string configured as the repository Actions secret `UNITY_LICENSE`. Do not share license credentials or GitHub tokens in chat. Once the workflow succeeds, download the APK from the workflow's Artifacts section.

## Current scope
This is an early prototype, not a finished AAA game. It has no voice acting, full campaign, external high-detail character assets, or cinematic sequences yet.
